# Отчёт о работе с AI Coding Agents

## Текущая организация работы

- Исходная ветка: `main`.
- Ветка текущего прогона: `beznames-copilot-implementation`.
- Второй прогон выполняется в независимой сессии и отдельной ветке,
  созданной также от чистого `main`.
- Ветки не используют изменения друг друга.

## Промпты и итерации

Для текущего прогона использовались следующие этапы:

1. анализ структуры, архитектуры и фактических требований;
2. технический аудит конфигурации и зависимостей;
3. добавление персональных ценовых уведомлений;
4. запуск миграций, тестов и HTTP smoke test.

Ключевые дополнительные запросы были вызваны фактическими ошибками проверки:

- исходные фиксированные зависимости не устанавливались на Python 3.15 из-за
  старого `grpcio`, поэтому требования обновлены до совместимых диапазонов;
- импорт Tinkoff SDK на этапе проверки Django ломал запуск без SDK/токена, поэтому
  интеграции переведены на ленивый импорт с явной ошибкой при отсутствии токена.

## Проверки

Результаты ветки `beznames-copilot-implementation`:

- `python manage.py migrate --noinput` — успешно;
- `python manage.py check` — успешно, проблем не найдено;
- `python manage.py makemigrations --check --dry-run` — изменений не найдено;
- `python manage.py test` — 12 тестов успешно;
- `Invoke-WebRequest http://127.0.0.1:8001/` — HTTP 200.

Добавлены тесты на создание наблюдения только для текущего пользователя и на
отсутствие повторных уведомлений для уже сработавшего условия.

## Ограничение сравнения

Второй прогон является независимой агентной реализацией. Называть его Gemini
можно только после фактического выполнения Gemini; Copilot не должен выдавать
свою работу за работу другого инструмента.
